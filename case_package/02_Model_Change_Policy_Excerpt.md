# Model change policy: excerpt (Model Risk Management)

1. **Classification.** Every change to a production model is classified by *scope* (what is touched: default definition, segmentation, technique, parameters only) and by *magnitude* (effect on expected loss).
2. **Materiality threshold.** A change whose effect on expected loss exceeds **10%** is material. Between 9% and 11% the requestor must show a sensitivity analysis.
3. **Approvals.** Model owner; independent validation; allowance (CECL) committee; Compliance for fair-lending items.
4. **Documentation.** Change request memo; technical report with validation evidence; updated monitoring plan.
5. **Anti-splitting.** Related changes submitted together or in the same cycle are assessed together.
