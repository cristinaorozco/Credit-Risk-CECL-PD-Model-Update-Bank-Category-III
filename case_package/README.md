# Case file: what the bank sends at the start

The documents a model-risk team would hand over to open the engagement. The loan-level extracts and the production tables are in `data/`.

| File | What it is |
|---|---|
| `00_Request_from_Model_Risk_Management.md` | The request and what is sent |
| `01_Model_Documentation_v1.md` | Summary of the production model (method, pools, parameters) |
| `02_Model_Change_Policy_Excerpt.md` | Materiality threshold (10% of expected loss), approvals, anti-splitting rule |
| `monitoring_pack/` | Latest quarterly monitoring results, backtesting by pool, discrimination at development, and the monitoring plan in force (v1) |
